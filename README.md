# Network Security Scanner (.NET Core)

Кросплатформний мережевий сканер, написаний на C# (.NET 8). Програма використовує системну утиліту `nmap` для глибокого сканування портів, визначення сервісів та їх версій.

 Поточний стан проекту
Наразі реалізовано базове ядро (Core) та консольний інтерфейс (CLI). Проект створено з дотриманням принципів чистої архітектури — логіка сканування та парсингу відокремлена від візуалізації.

 Основні функції (MVP):
*   Запуск процесу Nmap з параметрами визначення версій (`-sV`).
*   Парсинг результатів з XML за допомогою `LINQ to XML`.
*   Кросплатформеність: написана на Windows, успішно скомпільована (Self-contained) і протестована на Kali Linux.

 Використані технології
*   **Мова:** C# 12
*   **Платформа:** .NET 8.0
*   **Інструменти:** Nmap
